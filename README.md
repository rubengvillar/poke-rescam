# Poke-Rescam 🎴

**Poke-Rescam** es una plataforma web premium diseñada para coleccionistas de cartas Pokémon, permitiendo escanear cartas físicas, gestionar colecciones digitales, realizar intercambios y participar en mini-juegos temáticos.

## 🚀 Tecnologías
- **Framework**: [Astro](https://astro.build/) + React
- **Estilos**: Tailwind CSS + Framer Motion
- **Backend**: Firebase (Authentication & Firestore)
- **OCR**: Tesseract.js

## 🛠️ Instalación y Desarrollo
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Sincronizar cartas (opcional)
npm run sync-cards
```
